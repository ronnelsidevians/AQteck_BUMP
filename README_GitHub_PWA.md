# BUMP Search PWA v11 CENTERED

Виправлення: схеми відкриваються всередині поля `.modalImgBox`, повністю вписуються у поле і центруються. Контейнер схеми отримує розмір саме вписаного зображення, а зображення позиціонується всередині контейнера від `0,0`, тому не має відкриватися поруч або вилітати за поле.

Збережено:
- пошук карткових схем у `schemes/`, `cards/`, корені;
- пошук повних схем `AQteck_Bump_XX.png` у `sheets/`, `schemes/`, корені, з нулем і без нуля;
- повідомлення `Схему не знайдено...`, якщо PNG відсутній;
- pseudo-fullscreen тільки для повної схеми;
- PWA/offline.

Замінити у GitHub: `index.html`, `sw.js`, `manifest.webmanifest`, `icons/`, `favicon.ico`. Потім очистити Service Worker або відкрити `?v=11`.
