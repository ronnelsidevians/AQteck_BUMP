# BUMP Search PWA v37 ADAPTER SCRIPT FIXED

Виправлено проблему, коли частина JavaScript-коду адаптера відображалась як текст унизу сторінки.

## Причина
У v36 всередині JS-рядка був буквальний фрагмент `</script>`. HTML-парсер браузера закривав тег `<script>` раніше, ніж треба, і залишок JS показувався як текст на сторінці.

## Виправлення
Фрагмент замінено на безпечну форму:

```js
'<' + '/script>'
```

Тепер адаптер не ламає HTML, кнопка 🧩 працює, а код не показується на сторінці.

## Після оновлення
Відкрий сайт з `?v=37` або очисти Service Worker/cache.
