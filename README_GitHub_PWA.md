# BUMP Search PWA — GitHub Pages

Замінити у репозиторії: `index.html`, `manifest.webmanifest`, `sw.js`, `favicon.ico`, папку `icons/`. Для повного офлайну також потрібні `schemes/` і `sheets/`.
