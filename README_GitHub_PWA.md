# BUMP Search PWA v19

Зміни:
- якщо в картці є `KM...` або `KV...`, візуальна прив’язка об’єднує кілька проводів одного ланцюга в один вузол реле/контактора;
- вигляд: кілька клем/проводів ліворуч → один `Контактор/Реле` посередині → один блок `Модуль / канал` праворуч;
- COM/shared wire підсвітка збережена;
- popup по проводу/каналу групується по картці та має колонку `Реле/контактор`.

Після оновлення відкрийте сайт з `?v=19` або очистіть Service Worker/cache.
